# ## 钉哪个版本：以「生产实际跑过」为准，不要凭报告或记忆猜

# 踩过一次坑：最初按「报告说 >=0.5.0」钉了 `chromadb==0.5.23`，结果构建直接
# 失败 —— 它要求 `tokenizers <=0.20.3`，而本文件钉的是 `tokenizers==0.21.1`，
# ResolutionImpossible。

#     chromadb 1.5.9 / tokenizers 0.21.1 / youtube-transcript-api 1.2.4 / yt-dlp 2026.10.21

# 大版本跃迁。

# ⚠️ `yt-dlp` 的特殊性：
# 它更新频繁，且平台适配常依赖新版（B 站/YouTube 改版后旧版会失效）。
# 钉死是**为了可复现**，不是"永不升级"。建议：
#   - 每季度评估一次升级；
#   - 升级前用真实短链跑一次 downloader 冒烟（CI 里若有这类定时任务更好）；
