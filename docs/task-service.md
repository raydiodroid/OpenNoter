# 任务、存储与凭据边界

## 职责

`routers/note.py` 负责请求格式、身份、模型选择、配额检查和提交。`services/task_service.py` 是任务生命周期入口：创建 / 重试、状态、结果发布、删除、历史导入和中断恢复。`services/task_worker.py` 适配线程池，并保证构造生成器失败、提交队列失败也能进入终态。

`video_tasks` 是当前状态与归属的权威来源。每次提交创建新的 `attempt_id`，并在同一事务中追加 `task_attempts` 记录。重复提交正在执行的任务返回 409；旧批次不能覆盖新批次的状态和结果。后台回调携带提交时的批次号，不能在延迟执行时重新绑定最新批次。

`storage/task_files.py` 定义 `TaskStorage` 协议和本地实现。结果写入使用同目录独立临时文件、fsync 和原子替换；状态 JSON 是兼容镜像，其写入失败不会隐藏数据库状态。结果文件缺失或损坏会作为失败呈现，不再回退到无限等待。

删除先提交数据库删除标记，再清理结果、指纹缓存、截图和向量索引。正在执行的任务拒绝删除。清理失败保留日志及删除标记，访问控制仍拒绝读取；残留的笔记文件仍计入该用户的存储占用。

## 配额与执行

并发配额查询数据库；每日配额统计最近 24 小时的提交批次，重试计为新批次，删除笔记不退还次数。升级无法重建历史上未记录的重试，因此每条旧任务只回填一次历史提交。

`TASK_MAX_WORKERS` 控制工作线程数，默认 6；`TASK_MAX_QUEUED` 限制执行中与排队任务总数，默认 200。`TASK_TIMEOUT_SECONDS` 默认 1800 秒，在阶段切换处检查。Bcut 每任务创建独立上传会话，请求有连接 / 读取超时，轮询有时间上限；Groq 客户端也有超时。

转写器在确实需要转写音频时才初始化。提交、查询、恢复任务不加载 Whisper。已有字幕的任务可直接进入总结。需要本地转写时才检查对应模型是否已下载，未就绪则给出任务失败原因；个人在线 ASR 不受站点本地模型下载状态影响。

当前支持单个后端进程 / 单副本。配额检查与提交、任务产物发布使用进程内锁，线程池不是持久化队列。启动会把上次未完成任务标为失败，用户可重试；没有自动续跑或跨进程互斥保证。阶段超时无法强制中止卡在原生推理内部的线程。多副本与强制取消需要独立工作进程、持久队列和数据库租约，不能通过增加 uvicorn workers 实现。

存储配额涵盖按任务归属的笔记结果、转写 / Markdown 缓存和截图，不是上传目录、全局视频缓存及向量库的完整磁盘硬限额。

## 凭据传递

任务持有用户 ID 与无密钥的请求快照。上游调用在 `credential_resolver.py` 中解析一组不可拆分的「端点、Key、模型、来源」，禁止从一处拿用户 Key、从另一处拿站点端点。

站点 ASR 供应商独立存储在 `asr_providers` 表，包含名称、图标、引擎、端点、加密密钥、模型和启用状态。首次读取会幂等导入旧 `groq` 槽位及其模型配置；后续修改不再从旧槽位覆盖。可同时启用多个供应商，但 `transcriber_type` 只指向一个默认供应商 ID。停用默认供应商会让需要站点 ASR 的新任务明确失败，不会自动改用其他端点；删除默认供应商前必须先切换默认。内置引擎可停用但不能删除。

在线 ASR 也按用户解析凭据：shared 使用站点，optional 优先用户，required 缺少凭据直接失败；已有但损坏的用户凭据不会静默回退。没有个人 ASR 凭据且使用本地转写时，不要求付费上游凭据。个人 ASR 实例不进入跨用户共享缓存。

Web 缓存按 API 地址和用户 ID 分区，退出时清空可见任务、聊天及模型 / 凭据状态，并丢弃旧会话响应。插件按后端与 API Key 摘要分区，后台 worker 使用显式连接快照。旧的无归属浏览器缓存不会自动分配给下一位登录用户；服务器历史仍可重新同步，本地独有版本不会自动迁入。

任务列表支持 `include_deleted=true` 返回当前用户可见的删除标记和 `attempt_id`。Web 拉取所有分页，只依据明确标记删除本地条目；发现新批次时补拉正文并保留旧版本。分页期间发生变动可能延迟到下一次同步收敛，不会据此删除未见条目。

## 升级与验证

部署前备份 SQLite、`note_results`、截图与凭据加密配置，并停止旧后端进程。新进程启动时先执行幂等字段迁移、创建提交记录表，再导入历史状态文件；已有数据库状态不会被旧文件覆盖，归属用户不存在的文件不会转为匿名公开内容。不要让旧版和新版同时写同一数据目录。回滚代码前应恢复对应数据备份。

回归测试覆盖真实临时 SQLite 的并发重试、归属、旧批次拒写、配额、原子文件替换失败、中断恢复、缺失产物、删除标记、旧库重复迁移与 ASR 凭据；客户端测试覆盖缓存隔离、迟到响应、完整分页、删除标记、版本刷新和插件 API 契约。插件另有打包产物的 Playwright 冒烟测试。

这些自动测试模拟平台与模型响应，不证明每个视频平台当前的反爬策略、真实 Cookie、模型余额或 Firefox API 行为均可用。

### 模型选择与 BYOK 策略

Web 的「模型配置 → AI 模型」设置默认 AI 模型；「音频转写」中选择服务并设为默认。不再使用独立的默认设置分页。AI 默认模型持久化到 `config/model_defaults.json`；转写沿用 `config/transcriber.json`，不会新增另一份转写默认值。

- 明确选择 AI 模型时，供应商、模型和凭据来源绑定；不会因为用户另有个人凭据而替换站点密钥。`required` 策略拒绝明确选择站点模型。
- 自动模式：`shared` 使用站点；`optional` 优先个人 AI 凭据，再用个人通用凭据，未配置才用站点默认；`required` 必须有个人凭据。个人凭据损坏或地址不被允许时报错，不回退站点。
- 站点没有显式默认值时保留旧行为，按稳定模型 ID 顺序选择首项。已设置的默认模型失效时必须重新选择；只有模型名且多个供应商同名时拒绝猜测。
- AI 问答和生成笔记使用同一解析器。Web 生成页的「自动」及插件未指定模型时由后端执行上述规则；明确选择仅覆盖对应请求/浏览器配置，不改全局默认。
- 转写独立使用 `asr_mode`。允许个人转写时优先专用 ASR 凭据；仅当 `asr_use_default` 开启时使用个人通用凭据。AI 专用凭据不作为转写兜底。站点内置免费/本地引擎无需个人在线凭据；只用字幕的任务不会调用 ASR。
- `allow_custom_base_url=false` 时，个人接口必须与 `allowed_base_urls` 中的完整地址匹配（忽略末尾 `/`）。保存、模型发现、连通检查及实际调用都受约束；原有私网安全限制继续生效。
- Cookie 的 `shared/optional/required` 策略独立。`optional` 且未配置个人 Cookie 时，只有 `allow_shared_cookie_fallback=true` 才回退站点；否则按未登录身份下载。个人 Cookie 损坏始终不回退站点身份。`required` 必须有对应平台的个人 Cookie；缺失、无法解密或已知过期时，在提交与执行前拒绝任务，下载器不得吞掉策略错误后匿名访问。本地上传不受影响。旧通用 `mode=required` 仍迁移为 Cookie `optional`，仅显式设置 `cookie_mode=required` 才开启强制模式。

旧策略没有 `asr_mode` 时继承原 `model_mode`；首次局部更新会固化当前值，之后两种能力分别配置。所有新增开关的兼容默认值保留既有部署行为。站点策略位于「站点设置」，个人凭据位于「模型配置」，插件的对应入口按两种能力分别显示。

供应商图标使用标准库：Web 使用 Spectrum 2 和 LobeHub Icons；插件使用 Iconify 提供的 Lucide / Simple Icons。自建统一网关使用标准网关/网络图标，不使用自绘路径或自定义图片。

工作台新增本次任务的音频转写选择（`asr_provider_id`）：空值为自动、`own:asr` 为个人转写、其余为已启用站点 ASR ID。明确选择站点服务不会被个人凭据覆盖；强制个人在线转写策略仍优先校验。字段进入任务请求快照并传给执行器，重试保留。字幕优先，选项仅在需要音频转写时生效。实际 ASR 缓存记录选择来源，更换服务不复用另一服务的缓存；平台/客户端字幕仍可复用。插件同步提供同样的任务转写选择。
